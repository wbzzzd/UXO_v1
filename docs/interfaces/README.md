# interfaces/ — 外部接口契约

本目录收录本仓与外部组件/仓库之间的**接口契约文档**（双方共同遵守的冻结约定）。契约是系统级资产，不按功能单设目录；未来新增外部链路契约一律归入本目录。

## 权威边界

- 契约一经双方确认即冻结，修改须走需求变更（关联 `REQ-NNN`）并同步两侧实现。
- 契约描述**跨仓/跨进程约定**，与本仓内部设计文档（`docs/features/`）性质不同：内部设计随实现演进，契约变更必须显式版本化。
- 契约配套的本地中间件部署物统一在仓根 `docker-compose.yml`（全系统中间件清单），开发/CI 工具在 `scripts/`。
