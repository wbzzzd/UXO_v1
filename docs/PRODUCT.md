## 3. TARGET、CURRENT、NEXT 定义

- **TARGET**：产品最终要交付的指挥席客户端意图。来自业务目标、SRS 和用户已批准的版本范围，是后续设计与开发的依据。TARGET 不是当前实现事实，本文描述 TARGET 时不暗示已实现。
- **CURRENT**：当前源码、CMake 和测试已经形成的能力。来自实际审计，只描述现状，不反向修改产品需求。
- **NEXT**：已确认产品边界但尚未批准实施的下一批需求草案，由本文第 9 节统一编号并管理状态。NEXT 在架构与 UI 设计评审通过并批准之前不得直接指导实现，且不属于 CURRENT。

## 5. TARGET 产品意图

### 5.1 用户与产品定位

`UXOMissionControl` 是面向指挥席用户的桌面客户端，用于汇集目标、任务和设备信息，支持指挥席用户完成态势研判、处置决策、资源指派、执行监控与结果反馈。本仓库交付客户端本身，不交付无人机、传感器、排爆机器人、AI 模型、通信服务器、数据库和安全执行链等外部环境。

TARGET 面向指挥席客户端用户；最终的角色、权限、登录和多席位模型不由本文预先确定，留待后续需求与设计评审。NEXT 作为已确认产品边界但尚未批准实施的草案，使用单一指挥席用户，不实现登录、角色切换、外部通信、持久化、真实设备控制、UXR 或 MOS（见第 9 节）。

### 5.2 用户场景

TARGET 指挥席用户预期可以查看目标、任务、设备、告警和态势信息；选择目标并查看完整详情和识别结果；查看决策依据、候选方案和资源约束；指派设备、确认任务并监控执行反馈；查看操作日志、告警和历史结果；并清楚区分正常、加载、空、错误、降级和模拟状态。

### 5.3 端到端指挥工作流（目标，未实现）

TARGET 期望的完整指挥环是：

```text
汇集多源目标
  -> 比较多个目标并选择
  -> 查看决策依据与方案
  -> 指派可用设备
  -> 确认并下发任务
  -> 监控任务、设备和目标状态同步变化
  -> 接收执行反馈与完成结果
  -> 操作日志全程可查
```

该工作流属于 TARGET，不等于当前实现。当前已验证环路见第 7 节，且尚未形成“比较多个目标 -> 选择方案 -> 指派设备 -> 执行任务 -> 设备和任务反馈”的闭环。

### 5.5 交付边界

本仓库负责：

- 指挥席桌面客户端、页面和用户交互。
- 客户端内目标、任务、设备和操作日志的业务流程。
- 本地模拟场景与模拟操作。
- 获批后的外部系统客户端接入边界。

本仓库不负责无人机、传感器、排爆机器人固件与控制器、AI 模型训练、通信服务器、数据库服务和真实安全执行链。它们是客户端的外部环境，不是本仓库交付物。

### 5.6 安全含义

TARGET 不改变 [AGENTS.md](../AGENTS.md) 与第 10 节的安全边界。真实设备控制、真实排爆或抢修动作、真实数据库与通信接入不属于本仓库交付范围，需要单独评审和授权。

## 7. CURRENT 已验证目标状态操作闭环

```text
启动客户端
  -> 加载固定模拟场景
  -> 在目标表选择唯一目标
  -> 模拟确认
  -> 模拟处置
  -> 模拟完成
  -> 查看目标状态和进程内日志同步更新
```

- **验证结果**：目标表、流程面板和决策状态标签与操作日志在七步内同步变化。
- **证据**：`simulation_workflow_ui` 自动测试（详见 [DEVELOPMENT.md](./DEVELOPMENT.md)）。
- **未验证/未包含的能力**：多目标比较、方案选择、设备指派、任务执行、设备反馈、持久化，以及 3D 渲染结果、导航切换、视频源、告警交互、紧急停止效果、配置和历史功能。

该操作闭环只覆盖单目标状态流转，尚未形成完整指挥闭环。完整闭环所需能力见第 8 节，NEXT 候选范围见第 9 节。

### 9.3 范围与批准门禁

**包含范围**：单一指挥席用户的本地模拟会话状态、设备指派、任务执行、跨面板反馈、可复现场景和完整操作记录。

**排除范围**：登录、角色切换、外部通信、持久化、真实设备控制、真实排爆或抢修动作、UXR、MOS。

**批准门禁**：NEXT 必须先通过架构与 UI 设计评审并获用户批准，才能进入实现计划。架构依据见 [ARCHITECTURE.md](./ARCHITECTURE.md)，UI 依据见 [UI.md](./UI.md)。

## 10. 强制安全边界

- 不发送真实设备控制命令，不执行真实排爆或抢修动作。
- 不把模拟状态描述为真实设备状态。
- 不写入真实数据库或外部系统，不接入未授权通信链路。
- UI 中的模拟操作和结果必须明确标注“模拟”或“演示”。
- 真实安全执行链不属于本仓库；任何未来接入必须单独评审和授权。

紧急停止占位与上述边界关联，并由 [AGENTS.md](../AGENTS.md) 强制执行。

## 11. 已确认产品决策

- 产品边界是指挥席客户端，完整系统是外部环境和需求来源。
- NEXT 目标是完整本地模拟指挥环，按能力验收，不写无依据工期。
- NEXT 使用单一指挥席用户。
- UXR、MOS 和真实接入不属于 NEXT。
- 旧 SRS 的系统级性能数字暂不成为当前客户端门禁。
