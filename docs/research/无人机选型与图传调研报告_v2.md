## 2. 需求重新定义

| # | 需求原文 | 集成商视角的翻译 |
|---|---------|-----------------|
| 1 | 提供开放的SDK或API接口，支持二次开发 | 成品无人机能输出**标准协议**的视频流（RTSP/RTMP）和遥测数据（MQTT/MAVLink），我们能直接拉流和订阅 |
| 2 | 支持可见光与红外双光载荷 | 购买的成品机型自带双光相机（可见光+红外），不需要我们自己去选型/挂载/集成 |
| 3 | 图传信号可被程序化接收与处理 | 地面站输出的视频流是标准RTSP/RTMP协议，我们可以用FFmpeg/GStreamer拉流解码 |
| 4 | 具备稳定的飞行控制能力，适合长时间盘旋 | 成品机型本身支持长时间续航+稳定悬停，不是我们需要实现的 |
| 5 | 适用于研发验证环境，性价比合理 | 项目开发期：仿真模拟数据源（零硬件成本）；联调测试期：买一套成品无人机 |

## 3. 成品无人机选型（即买即用）

### 3.1 首选：大疆 Matrice 4T + DJI Pilot 2 + Cloud API

**为什么这是集成商的最佳选择**：

DJI Pilot 2（遥控器内置的地面站软件）已经内置了"上云 API"功能——不需要我们开发任何 App，直接在遥控器上配置MQTT服务器地址，就可以将无人机的：
- **实时视频流** → RTMP 推送到你的服务器
- **飞行器遥测**（GPS位置、高度、姿态、速度、电量）→ MQTT 每秒推送
- **相机状态**（变焦倍数、云台角度）→ MQTT
- **媒体文件**（照片/视频）→ 自动回传

### 4.2 视频流接收——核心代码（Qt集成）

```cpp
// 方式1：FFmpeg 拉 RTMP 流（推荐，延迟最低）
// 依赖：libavformat, libavcodec, libswscale

#include <QThread>
#include <QImage>
#include <opencv2/opencv.hpp>

extern "C" {
#include <libavformat/avformat.h>
#include <libavcodec/avcodec.h>
#include <libswscale/swscale.h>
}

class RtmpVideoReceiver : public QThread {
    Q_OBJECT
public:
    void run() override {
        // 1. 打开 RTMP 流（URL 来自 MQTT /live topic）
        const char* url = "rtmp://192.168.1.100/live/drone-001";
        avformat_open_input(&fmtCtx, url, nullptr, nullptr);
        avformat_find_stream_info(fmtCtx, nullptr);

        // 2. 找到 H.264 视频流
        int videoStream = av_find_best_stream(fmtCtx, AVMEDIA_TYPE_VIDEO, -1, -1, nullptr, 0);
        AVCodecParameters* params = fmtCtx->streams[videoStream]->codecpar;
        const AVCodec* codec = avcodec_find_decoder(params->codec_id);
        AVCodecContext* codecCtx = avcodec_alloc_context3(codec);
        avcodec_open2(codecCtx, codec, nullptr);

        // 3. 逐帧解码
        AVPacket* pkt = av_packet_alloc();
        AVFrame* frame = av_frame_alloc();
        SwsContext* sws = sws_getContext(/*...*/);

        while (!isInterruptionRequested()) {
            av_read_frame(fmtCtx, pkt);
            avcodec_send_packet(codecCtx, pkt);
            avcodec_receive_frame(codecCtx, frame);

            // 转换为 QImage（渲染用）
            uint8_t* rgbData = new uint8_t[frame->width * frame->height * 3];
            sws_scale(sws, frame->data, frame->linesize, 0, frame->height,
                      &rgbData, &rgbLinesize);
            QImage qimg(rgbData, frame->width, frame->height, QImage::Format_RGB888);

            // 转换为 cv::Mat（AI推理用）
            cv::Mat cvMat(frame->height, frame->width, CV_8UC3);
            sws_scale(sws, frame->data, frame->linesize, 0, frame->height,
                      &cvMat.data, &cvMatStep);

            emit frameReady(qimg, cvMat);
            av_packet_unref(pkt);
        }
    }

signals:
    void frameReady(const QImage& renderFrame, const cv::Mat& aiFrame);
};
```

### 4.3 遥测接收——核心代码（MQTT）

```cpp
// 方式：QMqttClient (Qt 官方模块)
// DJI Cloud API 物模型 → MQTT JSON 解析

#include <QtMqtt/QMqttClient>

class DroneTelemetry : public QObject {
    Q_OBJECT
public:
    void connectToCloud() {
        m_client = new QMqttClient(this);
        m_client->setHostname("192.168.1.100");
        m_client->setPort(8883);
        m_client->setUsername("appId");
        m_client->setPassword("appKey");
        m_client->connectToHost();
    }

private slots:
    void onConnected() {
        // 订阅遥测主题
        m_client->subscribe("thing/product/+/osd");   // 飞行数据 1Hz
        m_client->subscribe("thing/product/+/state"); // 飞行状态变更
    }

    void onMessage(const QByteArray& msg, const QMqttTopicName& topic) {
        QJsonDocument doc = QJsonDocument::fromJson(msg);
        // DJI 物模型 JSON:
        // {"latitude": 30.1234, "longitude": 120.5678,
        //  "altitude": 100.5, "attitude_head": 45.0,
        //  "horizontal_speed": 5.2, "battery": 85, ...}
        emit telemetryUpdated(doc.object());
    }
};
```

### 5.5 遥测模拟脚本（Python参考）

```python
#!/usr/bin/env python3
"""模拟无人机沿预设航线飞行，每秒推送 MQTT 遥测数据"""

import paho.mqtt.client as mqtt
import json
import time
import math

client = mqtt.Client()
client.connect("localhost", 1883)

# 预设航线：机场跑道上空的矩形盘旋路径
waypoints = [
    (30.2500, 120.1500, 100),  # lat, lon, alt(m)
    (30.2510, 120.1500, 100),
    (30.2510, 120.1510, 100),
    (30.2500, 120.1510, 100),
]

# 模拟飞行参数
speed = 5.0  # m/s
heading = 0
battery = 95

t = 0
while True:
    # 计算当前位置（沿航线移动）
    idx = (t * speed) // 100 % len(waypoints)
    lat, lon, alt = waypoints[idx]

    # 构造 DJI Cloud API 兼容的 OSD JSON
    osd = {
        "latitude": lat,
        "longitude": lon,
        "altitude": alt,
        "attitude_head": heading,
        "attitude_pitch": 0.0,
        "attitude_roll": 0.0,
        "horizontal_speed": speed,
        "vertical_speed": 0.0,
        "battery": {"value": battery},
        "gps_number": 15
    }

    client.publish("thing/product/MOCK001/osd", json.dumps(osd))
    heading = (heading + 1) % 360
    battery = max(20, battery - 0.01)
    t += 1
    time.sleep(1)
```

### 5.6 仿真 vs 真机的衔接

仿真环境的最大价值：**开发完毕后，只需要把 RTSP URL 从 `localhost:8554/visible` 换成无人机实际推流地址，其余代码一行不改。**

```cpp
// 从仿真切换到真机 —— 只需改这一行配置
#ifdef SIMULATION_MODE
    const QString videoUrl = "rtsp://localhost:8554/visible";
    const QString thermalUrl = "rtsp://localhost:8554/thermal";
#else
    // 来自 DJI Cloud API 返回的 RTMP URL
    const QString videoUrl = "rtmp://drone-server/live/visible";
    const QString thermalUrl = "rtmp://drone-server/live/thermal";
#endif
```
