## 第0级：纯仿真（¥0）——现在就开始

**不需要任何无人机硬件。** 这是研发阶段最重要的手段。

### 搭建方式（30分钟）

```bash
# 1. RTSP 服务器
wget https://github.com/bluenviron/mediamtx/releases/latest/download/mediamtx_linux_amd64.tar.gz
tar xzf mediamtx_linux_amd64.tar.gz && ./mediamtx &

# 2. 推送预录的无人机实拍视频（可见光通道）
ffmpeg -re -stream_loop -1 \
  -i drone_visible_footage.mp4 \
  -c:v copy -an \
  -f rtsp rtsp://localhost:8554/visible

# 3. 推送预录的红外视频（红外通道）
# 数据来源：FLIR Thermal Dataset / 网上下载的无人机红外侦察视频
ffmpeg -re -stream_loop -1 \
  -i drone_thermal_footage.mp4 \
  -c:v copy -an \
  -f rtsp rtsp://localhost:8554/thermal

# 4. MQTT Broker
sudo apt install mosquitto && mosquitto -d

# 5. 模拟遥测（Python 30行脚本，见v2报告5.5节）
python3 simulate_telemetry.py
```

### 视频素材获取

| 素材类型 | 来源 | 成本 |
|---------|------|------|
| 可见光航拍 | YouTube/B站搜索"drone aerial inspection"，下载公开视频 | ¥0 |
| 红外航拍 | FLIR 公开数据集 (https://www.flir.com/oem/adas/adas-dataset-form/) | ¥0 |
| 跑道场景 | 找无人机服务公司拍一段机场跑道俯拍素材 | ¥500-2000 |
| 含UXO目标 | 用3D模型合成（Blender/Unreal） | ¥0（人力成本） |

### 能完成的工作

- ✅ 视频流 RTSP 拉流、H.264 解码、QImage/cv::Mat 渲染
- ✅ 可见光 AI 目标检测（YOLO 等）
- ✅ 红外伪彩色图像的热斑/异常检测
- ✅ MQTT 遥测数据解析 + 3D 地图叠加
- ✅ 指挥席 UI 全流程联调
- ❌ 无法验证真实图传延迟和画质
- ❌ 无法验证真实 MQTT 数据格式（但 DJI Cloud API 文档有完整 schema）

## 第1级：消费级真机（¥4,788）——验证集成管线

**DJI Mini 4 Pro**

| 参数 | 详情 |
|------|------|
| **相机** | 1/1.3" CMOS, 4800万像素, 4K/60fps HDR |
| **图传** | O4, 20km, 1080p/60fps |
| **续航** | 34分钟（标准电池）/ 45分钟（Plus电池） |
| **重量** | <249g（无需登记） |
| **避障** | 全向避障 |
| **SDK** | **MSDK v5**（2025年3月起支持） |
| **RTMP推流** | DJI Fly App 内置，支持**自定义 RTMP 地址** |
| **价格** | ¥4,788（标准版，RC-N2 遥控器）<br>¥7,388（畅飞套装，含3电池+充电管家+ND滤镜+包） |

### 为什么这个够用

```
DJI Mini 4 Pro + DJI Fly App
  │
  ├─→ DJI Fly App "选择直播平台 → 自定义RTMP"
  │     rtmp://你的开发服务器:1935/live/drone
  │     → FFmpeg 拉流 → 解码 → 你的 Qt 应用
  │
  └─→ MSDK v5（如需更深度集成）
        开发一个简单 Android App，获取：
        - 飞行数据（GPS/姿态/高度/速度）
        - 相机参数控制
        - 视频帧数据
```

### 关键能力验证

- ✅ 真实 DJI 无人机 RTMP 推流格式兼容性
- ✅ 真实飞行画面中的 AI 检测效果
- ✅ MSDK v5 遥测数据获取
- ✅ 端到端延迟测量
- ❌ 没有热成像通道（红外继续用仿真）
- ❌ 没有 Cloud API（MSDK 需要开发 Android App）

### 购买注意

> **必须买 RC-N2 遥控器版**（¥4,788）。RC 2 带屏遥控器（¥5,988）不支持安装第三方 App（MSDK 无法使用），且不需要——反正你的 Qt 应用在 PC 上跑，不需要在遥控器屏幕上开发。

## 第2级：带热成像的行业机（¥30,798）——验证双光管线

**DJI Mavic 3T 无忧基础版**

| 参数 | 详情 |
|------|------|
| **可见光** | 4/3 CMOS 2000万像素 + 长焦56×变焦 |
| **热成像** | **640×512**, 点测温/区域测温/高温警报 |
| **续航** | 45分钟 |
| **图传** | O3 行业版, 8km+ |
| **RTK** | 厘米级定位（可选模块） |
| **SDK** | MSDK v5 + **Cloud API（MQTT）** + Thermal SDK |
| **价格** | ¥30,798（无忧基础版）<br>¥38,796（无忧旗舰版） |

### 和第0/1级的区别

| 能力 | 第0级仿真 | 第1级 Mini 4 Pro | 第2级 Mavic 3T |
|------|:--:|:--:|:--:|
| 可见光视频流 | 模拟 | ✅ DJI Fly RTMP | ✅ Cloud API RTMP |
| 红外视频流 | 模拟 | ❌ | ✅ 真实640×512 |
| 遥测数据 | 模拟 | ⚠️ 需MSDK开发 | ✅ Cloud API MQTT |
| 红外温度矩阵 | 模拟 | ❌ | ✅ Thermal SDK |
| 集成难度 | 极低 | 低 | 极低（Cloud API零代码） |

### 何时需要买

只有在以下条件之一满足时才需要买 Mavic 3T：
1. 仿真环境下红外 AI 模型已经调通，需要在真实红外画面上验证
2. 需要测试 DJI Thermal SDK 的温度矩阵提取管线
3. 需要验证 Cloud API 的 MQTT 遥测数据格式
4. 给客户做演示需要展示真实双光画面

**否则，继续用第0级仿真+第1级可见光验证就足够。**

## 消费级 vs 行业级的核心差异（对集成商而言）

| 维度 | 消费级（Mini 4 Pro） | 行业级（Mavic 3T/M4T） |
|------|---------------------|------------------------|
| RTMP推流 | DJI Fly App 内置 | DJI Pilot 2 内置 |
| 推流协议 | RTMP | RTMP/RTSP/GB28181/Agora |
| 遥测获取 | 需MSDK开发Android App | Cloud API MQTT直接订阅 |
| 红外相机 | ❌ | ✅ |
| Thermal SDK | ❌ | ✅ |
| 开发门槛 | 需要Android开发能力 | 纯后端（MQTT+RTMP） |
| 价格 | ¥4,788 | ¥30,798~43,076 |

**对你们的影响**：
- 如果用 Mini 4 Pro 做研发，获取遥测数据需要额外写一个 Android App（MSDK），这不涉及飞控，只是调用 DJI 的 Java/Kotlin API
- 如果用 Mavic 3T，**零代码即可获取遥测**（遥控器配置一个 MQTT 地址就行）

## 关键结论

1. **研发阶段不需要 M4T**。Mavic 3T 的 Cloud API、Thermal SDK、MSDK 与 M4T 完全相同，便宜 ¥12,000。

2. **甚至可以连 Mavic 3T 都不买**。纯仿真 + Mini 4 Pro (¥4,788) 即可完成 90% 的研发工作。红外相关管线用 FLIR 公开数据集 + 仿真验证。

3. **不要碰 Pixhawk/PX4/自组无人机**。那是造飞机的，跟你没关系。你只需要任何能推 RTMP 流 + 提供遥测数据的成品。

4. **从仿真切到真机的切换成本极低**：改一行 URL，其余代码不变。
