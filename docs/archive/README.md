# 历史文档归档

本目录保存不再直接指导当前开发的历史需求、架构和 UI 资料。归档内容只用于追溯和证据引用，不覆盖四份核心基线，也不代表当前实现。归档台账见 [`catalog.md`](catalog.md)。

归档文件按当前暂定的资料性质分目录：`core-baselines/`、`requirements/`、`architecture/`、`ui/`。目录层级仍可在后续归档治理中调整，文件台账不依赖目录命名。

归档规则：每次归档必须在 [`catalog.md`](catalog.md) 登记原始路径、归档路径、归档时间、归档原因、当前替代权威和字节保留方式；保留历史内容和 Git 追溯关系；归档文件与 [`../PRODUCT.md`](../PRODUCT.md)、[`../ARCHITECTURE.md`](../ARCHITECTURE.md)、[`../UI.md`](../UI.md)、[`../DEVELOPMENT.md`](../DEVELOPMENT.md) 冲突时，以核心基线为准；归档资料不得触发实现。目录层级调整时，先更新台账，再移动文件并保留原始路径记录。
