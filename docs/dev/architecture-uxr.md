## 1. 范围与非目标

### 1.1 范围

- 一个概念上的、应用拥有的内存模拟识别会话，统一持有已接受的模拟识别输入与派生结果、人工选择、模拟人工决策与修正，以及唯一一份进程内内存模拟识别日志。
- 确定性模拟识别计算（概念职责）作为纯模拟边界，只构造输入或产出派生结果并回交会话。
- `TargetInfo` 的识别字段作为模拟会话中已接受的派生数据，默认值须保持现有客户端兼容。
- 目标详情页中的模拟识别结果展示与人工确认/驳回/修正草案。

### 1.2 非目标

- 真实 AI 推理、真实传感器输入、真实弹药数据库或外部通信。
- 真实当量判断、真实安全距离决策、真实排爆动作。
- 在本草稿中确定具体模型、通信协议、数据库结构、运行时持久化或部署方式。
- 给置信度、型号/类型、来源、`YieldEstimate` 等字段赋予真实识别、当量、安全距离、工程或执行含义；这些字段都是合成演示属性。

## 2. 数据与服务边界

本节定义本文 Draft 自包含的 UXR 候选边界，不引用核心 [`../ARCHITECTURE.md`](../ARCHITECTURE.md) 的任何章节。

1. 概念上存在一个应用拥有的内存模拟识别会话，是已接受的模拟识别输入/结果、人工选择、模拟人工决策与修正，以及唯一一份进程内内存模拟识别日志的唯一权威；UI 只保存选中索引、折叠状态等展示状态。
2. 确定性模拟识别计算/服务（概念职责）是纯模拟边界，只构造输入或产出派生结果并回交会话，不拥有、不直接修改权威业务状态。
3. `YieldEstimate`、置信度、型号/类型、来源和识别状态都必须带模拟或占位标识，均为合成演示属性，不具有真实识别、当量、安全距离、工程或执行含义。
4. 模拟识别操作日志只记录本地模拟操作，不代表真实识别审计或安全批准；不新增通用 Repository、Store、服务容器、事件总线或预留外部接口。

## 3. 识别流程

规范流程（本文 Draft 自包含候选）：

```text
UI 请求（确认/驳回/修正或查询）
  -> 应用校验
  -> 纯模拟识别计算/服务回交派生结果
  -> 模拟会话状态与中心内存模拟日志原子提交
  -> 一次变更通知
  -> UI 回查权威模拟会话状态并渲染
```

被拒绝或无效的确认/驳回/修正请求必须返回原因，在同一模拟日志中原子追加一条拒绝记录，且不改变业务状态。

具体状态枚举、字段命名和人工确认验收以 [`prd-uxr.md`](prd-uxr.md) 的 Draft 内容为来源，须经过独立需求、架构和 UI 评审后才能进入功能设计。

## 4. UI 与核心模块关系

- 核心数据与模拟识别服务不依赖 QWidget。
- UI 只展示模拟识别结果与模拟操作反馈，不把结果写成真实设备状态或真实安全状态。
- UI 不保存可独立修改的业务状态；状态变化经一次统一通知后由 UI 回查权威模拟会话状态。
- 目标详情页的控件契约由 UI 设计流程维护，本文件不复制具体布局。
