## 1. 项目信息

- **项目名称**：UXO_v1 排弹抢修指挥系统
- **技术栈**：Qt 5 / CMake / C++17 桌面客户端，目标程序 `UXOMissionControl`
- **MVP 约束**：仅允许本地模拟、只读分析、接口占位；禁止接真实设备/真实 AI/真实数据库写入（见 `AGENTS.md` 安全边界）
- **功能定义**：在 MVP 阶段以模拟识别服务 + 数据结构 + UI 展示 + 人工确认回路的方式落地，为未来真实 AI 接入留好接口边界

---

## 2. 产品目标

| 编号 | 产品目标 | MVP 阶段定位 |
|------|---------|-------------|
| UXR-G1 | 建立未爆弹识别结果的完整数据模型，覆盖类型、子型、置信度、当量估算、识别方法和降级链状态 | 扩展现有 `TargetInfo`，纳入 DDR-008 提出的 `YieldEstimate` 结构 |
| UXR-G2 | 提供模拟识别服务，基于演示场景生成可信的识别结果，模拟型号识别->融合->保守降级的分层链 | 纯本地模拟，输出预定义识别结果，不接真实 AI |
| UXR-G3 | 提供人工确认回路：操作员可查看识别详情、确认/驳回/修正识别结果，修正优先级高于自动估计 | 人始终在回路中，符合 DDR-008 降级链的并行通道设计 |

## 3. 用户故事

| 编号 | 用户故事 |
|------|---------|
| UXR-US1 | 作为操作员，我希望在目标列表中看到每个未爆弹的识别类型、置信度和当量估算，以便我快速了解威胁概况。 |
| UXR-US2 | 作为操作员，我希望点击某个目标后能看到识别详情（识别方法、数据来源、不确定度），以便我判断识别结果是否可信。 |
| UXR-US3 | 作为操作员，我希望能确认、驳回或手动修正识别结果，以便在 AI 识别有误时由人工兜底。 |
| UXR-US4 | 作为指挥员，我希望看到识别降级链的当前状态（型号识别成功/降级到保守假设），以便我了解当前安全距离的置信水平。 |
| UXR-US5 | 作为维护员，我希望模拟识别服务的数据是可配置的，以便我构造不同的演示场景来测试识别流程。 |

## 4. 需求池

### P0 - MVP 必须有的最小可用闭环

| 需求编号 | 名称 | 描述 | 验收标准 | SRS 对应 |
|---------|------|------|---------|---------|
| UXR-001 | 识别结果数据模型 | 扩展 `TargetInfo`，新增识别相关字段：`recognizedType`、`recognitionConfidence`、`yieldEstimate`（含 nominalYield/uncertainty/confidence/estimationMethod）、`recognitionSources`、`recognitionStatus`（AutoDetected/Confirmed/Rejected/ManualOverride）、`recognitionTime`。 | 1) 新增字段有默认值，不破坏现有 `TargetInfo`；2) `YieldEstimate` 含 4 个字段；3) `estimationMethod` 支持 MODEL_ID/DIMENSION/FUSION/MANUAL/CONSERVATIVE；4) 注释标注"模拟数据结构，预留真实 AI 接口" | F-027, F-030, F-031, F-032；DDR-008 |
| UXR-002 | 模拟识别服务 | 实现 `MockRecognitionService`，模拟 DDR-008 降级链：80% 型号识别（HIGH，±5-15%），15% 多源融合（MEDIUM，±30-50%），5% 保守假设（CONSERVATIVE，类别最大值×1.5）。基于内置模拟弹药数据库（5-8 种）。 | 1) 输入 `TargetInfo`，输出含识别字段的 `TargetInfo`；2) 同一目标多次调用结果一致（确定性）；3) 概率分布可配置；4) 类名含 `Mock` 前缀，标注"模拟服务" | F-020~F-023, F-025~F-028, F-031 |
| UXR-003 | 识别结果 UI 展示 | 展示识别类型、置信度（进度条）、当量估算、置信度等级、识别方法、数据来源。低置信度橙色高亮。 | 1) 独立分区展示；2) 置信度有视觉等级区分；3) 当量格式"45.0 ± 6.8 kg TNT"；4) 来源列表；5) 标注"模拟识别结果" | F-032, F-072 |
| UXR-004 | 人工确认回路 | 确认/驳回/手动修正三种操作。修正后 `recognitionStatus` 更新，`estimationMethod` = MANUAL。 | 1) 三个按钮；2) 修正弹对话框；3) 状态即时更新；4) 写入操作日志；5) 修正后 `estimationMethod` = MANUAL | F-027, F-092；DDR-008 |
| UXR-005 | 识别服务接口抽象 | `IRecognitionService` 纯虚接口，`recognize(const TargetInfo&)` 方法。`MockRecognitionService` 实现。 | 1) 纯虚类；2) Mock 公开继承并实现；3) 注释说明未来真实 AI 接入方式；4) 接口位于 `include/Core/Recognition/` | F-020~F-032 |

## 7. 安全边界声明

- 所有识别结果由本地模拟服务生成，标注"模拟识别结果"，不连接真实 AI 推理引擎
- `MockRecognitionService` 类名含 `Mock` 前缀
- `IRecognitionService` 接口为未来真实接入预留边界，注释标注"尚未接入"
- 所有模拟数据不写入真实数据库，仅存在于内存或本地 JSON 配置
- 当量估算数据结构遵循 DDR-008 降级链设计，安全距离公式参数可配置
