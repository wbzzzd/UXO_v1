## 1. 问题与目标

### 1.1 问题

当前 MVP 完成了单目标四状态流转闭环，但演示效果"悬浮"：

- 中心区视频面板是 4 格定时变化的 `REC` 文本占位，无视频源（`src/MainWindow/VideoStreamPanel.cpp`）。
- 右侧态势视图是 Qt3D 机场场景，用户已判定 Qt3D"完全不可用"，决定改 2D 战术地图。
- 启动即加载 1 目标 1 任务 2 设备的固定场景，无探测过程呈现（`src/MainWindow/MainWindow.cpp::loadMockData`）。
- 所有交互本质是"点表格行 -> 枚举状态变化 -> 另一处文字同步变化"，探测/识别/规划三阶段全缺。
- `DemoScenarioProvider` 用经纬度 (108.9, 34.2) 塞进本地米坐标系，坐标语义混用（`src/Core/Simulation/DemoScenarioProvider.cpp`）。

### 1.2 目标

把态势页改造为"探测阶段动态演示"：视频驱动目标流入、2D 战术地图显示态势、四区同步、80 秒 5 目标。演示从"悬浮枚举变化"变成"有真实感的探测过程"。

### 1.3 与 SRS 四阶段的关系

SRS《排弹抢修指挥系统》v1.0 定义四阶段：探测 -> 识别 -> 规划 -> 排弹。本功能只做**探测阶段**。识别/规划/排弹属于后续独立功能，各自走审批流程，不在本功能范围内。

### 1.4 与探测页设计文档的关系

`docs/ui/pages/detection.md` 定义了独立的探测页 UI 规格（左面板搜索/筛选/目标表 + 中心区证据 Tab + 右面板详情/时间线），属于 TARGET/Draft 设计评审原型，**不是本功能的实现规格**。本功能改造的是态势页中心区，不新建探测页。探测页设计文档是后续识别阶段的参考输入。

## 3. 用户流程

### 3.1 主流程

1. 启动客户端，态势页可见，中心区上半 2D 战术地图（空，只有卫星底图），下半视频区（黑屏，显示"等待开始"），目标表/告警/日志全空。
2. 点击顶部 [开始] 按钮。
3. UAV-1 视频开始播放，2D 地图保持显示底图。
4. 视频播放到 10s，程序在视频画面叠加红框（闪烁 2 次，1 秒后消失）；同时目标表插入第 1 行，2D 地图加第 1 个红点（脉冲动画 + ID 标签），告警面板插入 1 条，日志追加 1 条。
5. 25s/42s/60s/78s 重复步骤 4，共 5 个目标流入。
6. 80s 视频播放结束，自动暂停；目标流入停止；已有 5 个目标保留在目标表/2D 地图/告警/日志中。

### 3.2 重置流程

1. 点击顶部 [重置] 按钮。
2. 视频停止并回到 0s，2D 地图清空所有红点，目标表清空，告警清空，日志清空。
3. 回到启动初始状态。

### 3.3 结束流程

1. 点击顶部 [结束] 按钮。
2. 视频暂停（不回 0s），目标流入停止，已有目标保留。
3. 区别于 [重置]：[结束] 保留现状，[重置] 清空一切。

### 3.4 目标点击

- 点击 2D 地图上的红点，该红点高亮（边框加粗或颜色变化），目标表对应行高亮选中。
- 点击目标表行，2D 地图对应红点高亮。

## 9. 待确认事项

### 9.1 外部素材

本功能需要两份外部素材，由用户提供：

| 素材 | 规格 | 用途 |
|------|------|------|
| 机场航拍视频 | 80 秒，机场俯视，MP4 格式 | UAV-1 视频画面 |
| 机场卫星图 | 通用民用机场俯视图，PNG/JPG | 2D 战术地图底图 |

**已确认决策**：用户暂不提供素材，实现阶段先用占位素材（纯色背景底图 + 短时长测试视频循环），后续用户提供后再替换。占位素材不阻塞功能验收，验收项以"机制可用"为准（视频能播放、红框能叠加、底图能显示、坐标映射正确）。

### 9.2 告警/日志布局

CURRENT 告警面板和操作日志在中心下半部。本功能把中心下半改为视频区后，告警/日志需要重新定位。

**已确认决策**：采用方案 B —— 保留中心下半右侧（视频区左 + 告警/日志右，水平分割）。理由：改动最小，不破坏左面板目标表/任务表/设备表的现有垂直布局，也不侵入右面板设备状态/决策建议。视频区与告警/日志在同一中心下半水平分割，由 QSplitter 控制。

### 9.3 Qt3D 代码处理

`SituationView.cpp/h` 和 Qt3D 依赖保留不删，探测页不使用。后续确认不再用 Qt3D 时再清理，属于独立任务。

### 9.4 探测脚本数据

5 个目标的类型/置信度/威胁等级/坐标具体值，实现阶段根据视频内容确定，不阻塞功能审批。类型从 `TargetInfo::Type` 枚举中选取（现有枚举：AntiRunwayBomb / ArtilleryShell / Rocket / ClusterBomb / Unknown）。
