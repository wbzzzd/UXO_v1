# 数据平台接入（客户端适配器）

状态：Implemented（2026-10-12 验收；2026-10-10 用户批准）
关联产品需求：REQ-012
关联版本：待确认

## 1. 问题与目标

数据平台服务端已实现并验证（154 项测试锁定，含契约响应键集快照），API 契约 v1.0.3 于 2026-10-10 经本仓评审通过（附 3 条非阻断意见，评审记录：`.omo/plans/20261010-dataplatform-contract-review.md`）。客户端侧尚无外部数据边界：无网络、存储或服务适配器，全部状态在内存，重启即失。

目标：构建客户端适配器库，完整实现契约 v1.0.3 语义并与本地数据平台实例联调验证，为后续业务链路（检测记录上报、目标持久化、任务同步等）提供唯一接入通道。

## 2. 范围与非目标

**范围**（P0，纯适配器层）：

- 新增 `Integration` 静态库（`src/Integration/`、`include/Integration/`）：
  - HTTP/JSON 客户端（QNetworkAccessManager），基址经配置解析，默认 `http://127.0.0.1:8080`；
  - 健康检查、词表（9 表 61 项）、模型类映射（8 行）加载与只读缓存；
  - 五实体单条/列表查询、创建（POST）、全量更新（PUT）；分页与起步过滤集参数构造；
  - 契约 JSON ⇄ `Core::Types.h` 结构体双向映射（UUID 两形式、时间戳三形式、可空字段显式 null、类型严格）；
  - 契约错误模型 → 内部错误类型：以 `field`+`code` 为准，不解析 `message`；400 聚合错误完整保留。
- 契约一致性测试：对本地数据平台实例执行（健康/词表/映射/五实体 CRUD 往返/错误码/分页过滤/409/400 聚合/类型严格性），测试数据只写本地实例；真实实例测试为标准门禁，录制 fixture 回归为后续可选补充。
- 评审记录"适配器实现注意事项"7 条落实：Qt JSON 整数严格性、battery_level 取整、result null↔0 语义、raw_result 必填、health 503 专属响应体、模拟上报通道限制、默认回环基址。
- 核心文档回写（见 §8）。

**非目标**：

- 不改 UI、页面流程与导航；不新增用户可见功能。
- 不替换现有模拟状态权威（SimulationWorkflow/MainWindow 行为不变）；不把模拟链数据作为真实数据上报。
- 不接生产库、不直连数据库（不启用 `Qt5::Sql`）；不做非回环部署形态。
- 不实现认证/授权（契约 `Authorization` 仅预留）；无删除操作（契约 v1 无删除端点）。
- 不修改契约语义（变更走契约 §9.2 双仓流程）；不修改 UXO_DataPlatform 仓任何文件。
- 不新增通用 Repository/Store/事件总线（ARCHITECTURE §5 禁止为无调用方的未来模块建抽象）。
- 业务状态机流转仍由客户端负责（契约 §6.0 服务层不强制）。

**后续候选**（本批不做，待单独登记）：检测记录真实上报链路、目标/任务/告警与平台双向同步、UI 连接状态指示、历史视图（需契约时间范围过滤扩展，见评审意见 1）。

## 3. 用户流程

无新增用户流程。P0 为适配器层能力，不改变现有页面交互与模拟行为。连接配置方式（环境变量/配置文件/启动参数）在实施计划中确定，默认零配置连本地实例。

## 4. 需求增量

关联 REQ-012（数据平台接入）。无其他需求增量。

## 5. 架构增量

- 新增 `Integration` 静态库 CMake 目标，依赖 `Core`（`Data/Types.h`）与 `Qt5::Network`；不依赖 MainWindow/UI。
- 根 CMake 已查找但无目标使用的 `Qt5::Network` 首次生产启用；`Qt5::Sql` 保持不使用（客户端不直连数据库）。
- 过渡形态说明：TARGET 架构中 `Integration` 依赖 Application 与 Domain（ARCHITECTURE §5），该两层尚不存在；本批适配器依赖 CURRENT `Core` 中的领域类型，待 Application/Domain 落地后随模块映射（§6.1）迁移归属，不预先创建 TARGET 层空目标。
- 状态所有权不变：适配器无状态（词表/映射为只读正典缓存），不成为任何业务状态权威。

## 6. UI 增量

无。
