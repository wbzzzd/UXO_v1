# REQ-010: UI 视觉治理

| 字段 | 值 |
|------|-----|
| ID | REQ-010 |
| 所属 | 独立候选（不并入 NEXT 切片） |
| 状态 | `Implemented` |

## 能力

指挥席客户端 UI 视觉治理：统一 token 执行、跨平台外观一致、可读性达标、图标体系建立

## 解决的当前缺口

`GlobalStyle` token 体系名存实亡（`src/` 有 215 处内联 `setStyleSheet` 散落 22 个文件绕开 token），未应用 Fusion 风格导致平台原生控件外露，可读性指标偏低（辅助文本对比度 4.8:1 处于临界值），几乎无图标辅助态势识别；`GlobalStyle.cpp` 存在 scrollbar hover 颜色错误、横向 scrollbar 缺 hover 规则、`QDockWidget` 引用缺失资源 `url(close.png)` 等已知缺陷

## 验收结果

`src/` 内联 `setStyleSheet` 降至 50 以下且无业务代码硬编码颜色字面量；全局应用 Fusion 风格 + 强制字体（`setFamilies` + `setPixelSize`），Linux xcb 与 Windows 控件外观一致；字号与对比度满足 WCAG AA（辅助文本 >= 4.5:1）；导航栏/工具栏/关键按钮配矢量图标且色盲友好；`design-system.md` token 与 `GlobalStyle` 源码完全一致；仅本地模拟数据，不接真实传感器、真实 AI、真实数据库或通信

## 批准事实

2026-08-14 批准事实（历史记录）：用户确认 UI 视觉升级改进方向，明确排除占位控件清理（工具栏 QLabel 占位、未实现导航页、菜单占位项保持现状）；确认军事指控视觉风格决策（暗色主题、高信息密度、克制装饰、威胁语义色阶、等宽遥测字体）是合理领域选择，本需求仅治理执行缺陷不改风格方向；选择走 REQ + features 治理路径。本次批准授权进入功能设计与执行计划阶段，不授权真实设备控制、真实排弹动作、真实数据库、真实通信或任何真实执行。

## 实现事实

2026-08-21 实现事实：三阶段治理完成（执行记录见 `.omo/plans/20260813-ui-visual-upgrade.md` 批次1-9 与阶段3）。阶段1：`src/` 内联 `setStyleSheet` 由 215 收敛至 89（用户裁决修订阈 ≤90 达标；剩余均登记保留：运行时动态态、完整复合样式、非等值 hex）；Fusion 风格与 `setFamilies`+`setPixelSize` 强制字体落地（`Application.cpp`）；缺口所述 scrollbar hover 与 `QDockWidget` 缺失资源缺陷经取证核实为不实。阶段2：TextSecondary 对比度 4.8:1 提升至约 6.3:1 达 WCAG AA；QtAwesome 矢量图标 14 枚挂载导航/地图工具栏/紧急停止，字形可区分保证色盲友好；圆角/间距 token 提升。阶段3：3.1 深度投影（Elevation token + `FloatingShadowLayer` 底衬 + DEC-GEN-MODAL 无边框模态重设计）落地；3.2 过渡动画经用户裁决取消；3.3 QSS 框架经评估与用户裁决不引入。验收终态：A1 Release 构建退出 0；A2 阶段1/2 每批 ctest 16/16 全绿，合并主干后终态 15/17（2 项失败为主干探测 ONNX 集成的既有问题，登记见 REQ-009 实现事实，与本治理线无关）；A3 89 ≤ 修订阈 90，业务代码无未附注颜色字面量；A4 三视口 + map 五页像素门禁已执行（Linux offscreen，DPR=1；xcb/Windows 真机复核留用户侧）；A5 `design-system.md` 与 `GlobalStyle` token 对账一致；A6/A7 阶段2 落地达标；A8 门禁截图含模拟标注；A9 改动限定视觉层白名单（门禁工具扩展经用户裁决登记）。合并主干后全量重链曾暴露 GNU ld 2.38 `push@GOTPCREL` 错误松弛缺陷（9/17 崩溃），已以 `-Wl,--no-relax` 规避并恢复 15/17。本治理线仅涉及视觉层与本地模拟数据，不接真实传感器、真实数据库或通信。
