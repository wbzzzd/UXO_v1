# REQ-011: Qt 客户端三视口适配

| 字段 | 值 |
|------|-----|
| ID | REQ-011 |
| 所属 | 独立候选（不并入 NEXT 切片） |
| 状态 | `Approved` |

## 能力

指挥席客户端 `UXOMissionControl` 三视口适配：壳层与三个已实现页面（态势、探测、决策/MOS）在 1280×720、1920×1080、3840×2160 三种视口下满足 `docs/ui/design-system.md` §7 视口规则，并以离屏像素门禁形成可复核证据

## 解决的当前缺口

六页 HTML 原型的三视口适配已于 2026-08-25 完成验收并提交（分支 `feature/prototype-responsive-viewport`，待合并），但 Qt 客户端实现侧尚无对应的系统性三视口验收：REQ-010 A4 门禁矩阵（`scripts/gate-capture.sh`）仅覆盖决策页三视口与态势页 1920×1080，且采集输出至 /tmp 临时目录、未在 `.omo/evidence/` 留存，态势页在 1280×720、3840×2160 档位与探测页在全部三档视口下均无 fresh 像素证据；决策页历史三视口几何证据（`.omo/evidence/mos-p0-qt-closure-final/REPORT.md`）采集于单档位渲染修正之前，已被 `UI.md` 判定不能作为修正后证据；`UI.md` 第 3 节、`design-system.md` §7.0 末段与 `docs/ui/README.md` §7 三处登记的"1280×720 下约 5px 底部溢出"所指 `DecisionSuggestionPanel` 等组件未纳入 CMake 编译目标，属过时记录

## 验收结果

三页（态势/探测/决策）× 三视口（1280×720/1920×1080/3840×2160）共 9 张离屏截图门禁全部执行并留存（Linux offscreen DPR=1，xcb/Windows 真机复核留用户侧）；1280×720 下三页区域无溢出、无意外裁切、关键内容可用；1920×1080 下与修复前基线零回归（动画帧差异除外）；3840×2160 下无大片留白、固定 token 区域与字体不缩放、仅中心区放大；Release 构建退出 0、ctest 不低于实施前基线；`UI.md`、`design-system.md` 与 `docs/ui/README.md` 的过时视口记录刷新为 fresh 事实；仅本地模拟数据，不接真实传感器、真实 AI、真实数据库或通信

## 批准事实

2026-08-26 用户批准三件套（REQ-011 + `docs/features/viewport-adaptation.md` + `.omo/plans/20260826-qt-viewport-adaptation.md`），批准范围含复用性说明（壳层适配与门禁基础设施供设备/统计/配置等后续页面复用）；动代码前需经计划阶段 2 问题清单裁决。
