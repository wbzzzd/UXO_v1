## 能力

MQTT 链路断链/恢复事件在客户端日志留痕（可观测性），并定制 keepalive 参数；（评估项）受控自动重连策略——属 m4e 功能设计 §6.1 数据源契约修订，须用户批准后方可实施

## 解决的当前缺口

2026-10-19 M4E 台架联调中 broker 于 16:42:48 断链后，客户端零重连、日志零 MQTT 记录（仅 UI 红徽标提示），真实静默丢遥测 ∈[2h11m, 2h39m]；现行 m4e 功能设计 §6.1 契约为「断链不自动重连、不回落模拟源（恢复＝手动两击模式切换）」，零重连系既定设计而非违约，但长时静默丢遥测缺乏链路层可观测性

## 验收结果（草案）

- MQTT 在线/断链/恢复三态均有客户端日志留痕；
- keepalive 定制生效（断链判定时延可配）；
- （评估项）受控自动重连策略经设计评审并修订 §6.1 契约后实施
