# REQ-012: 探地雷达样例数据展示与目标模拟演示

| 字段 | 值 |
|------|-----|
| ID | REQ-012 |
| 所属 | 独立候选（不并入 NEXT 切片） |
| 状态 | `Approved` |

## 能力

指挥席客户端接入探地雷达（GPR）样例数据回放展示：加载经外部路径配置的 MALA 格式阵列 GPR 数据集，在新增"雷达"页以 B-Scan 伪彩剖面图展示多通道数据（H/L 两组采集）并提供回放控制与增益模式切换；以阈值自动检测标记疑似目标候选（人工复核必需），经人工校验后注入统一目标列表并在 2D 战术地图落点，与视频 AI 检测确认的目标同构。

## 解决的当前缺口

当前客户端只有无人机视频 AI 检测（REQ-009 + DetectionEngine）一种探测来源；探地雷达是埋地未爆弹探测的核心传感器，客户端完全没有 GPR 数据接入、解析与展示能力。当前无实时雷达数据获取能力，仅有一段样例数据可用于演示（泰安测试 2025-11-13，MALA `.rad`/`.rd3`/`.cor`，H/L 两组采集 × 16 组收发通道，约 235MB，经外部路径引用、不入库；预研证实 H/L 为近重复记录，数据格式与检测可行性已经预研验证，证据见 `.omo/evidence/gpr-research/`）。

## 验收结果

（草案，待批准评审确认）

- 数据经外部路径配置加载（不入库）；路径未配置或文件缺失时雷达页显示明确降级态，不影响其他页面与其他功能。
- 导航新增"雷达"页（`QStackedWidget` index 3）：B-Scan 伪彩剖面图（横轴 = 测线道/距离，纵轴 = 深度，增益模式 AGC/固定/原始可切换）；H/L 数据组与 16 组收发通道切换；回放控制（播放/暂停/速度/进度拖拽）；当前道对应的 RTK 经纬度与时间戳实时显示。
- 阈值自动检测疑似目标候选（高反射聚集区；预研证实存在漏检与过检两类失效，仅作候选标记，人工复核必需）；右栏疑似目标列表展示 ID/道索引/深度/幅度，标注 [模拟][GPR自动检测]。
- 人工校验闭环：[确认目标] 后目标经 RTK 插值获得经纬度，注入统一目标列表（态势页目标表可见），2D 战术地图出现红点（标注 [模拟]），操作日志追加；[标记误报] 从列表移除并记日志。
- 确认后的目标走现有 `SimulationWorkflow` 四状态机，与视频 AI 检测确认的目标完全同构。
- GPR 演示与无人机视频回放相互独立，不做时间同步（两者非同场景采集）。
- 所有模拟数据明确标注"模拟"或"演示"；不接真实雷达设备、不发送任何设备命令。
- 测试：GPR 解析层单元测试（合成 fixture + 可选真实数据 smoke）、雷达页 UI 契约测试、全量 ctest 不低于实施前基线。

## 实现事实

- 数据层（阶段 1，commit `824b6fb`）：`GPR` 静态库（`src/GPR/` + `include/GPR/`）——GprRadarHeader / GprBScanData / GprTrack / GprDataset / GprThresholdDetector，仅依赖 `Qt5::Core`，不含 Widgets 代码。
- 雷达页（阶段 2，commit `f94a9cd`）：导航“雷达”（`QStackedWidget` index 3）= GprView + GprBScanWidget + GprSuspectPanel；B-Scan 伪彩（diverging 色标，AGC/固定/原始增益）、H/L 频段与 16 通道切换、回放条（播放/暂停/1×/2×/4×/进度拖拽/当前道 RTK 经纬度与时间戳）、数据缺失降级态。
- 人工校验闭环（阶段 3，commit `f94a9cd`）：[确认目标] → RTK 平滑轨迹插值经纬度 → 注入统一目标表 + 2D 地图红点（标注 [模拟]）+ SimulationWorkflow 日志，候选由 GprView 本地移除防重复注入；[标记误报] 候选移除 + 状态栏日志；无有效 RTK 定位的候选不注入（仅告警）。
- 交互冻结修复（commit `54b63aa`）：根因 `GprBScanWidget::rebuildImage` 在 GUI 线程逐道穿透 8 道 LRU 缓存读 9p 挂载盘，全通道重建阻塞数十秒、对比度滑块无防抖加剧；`GprBScanData` 新增 `preloadAllTraces()`/`isFullyLoaded()` 整读预载（雷达页工作者线程 detect 前预载，未预载回退 LRU），`setContrast` 改 120ms 防抖；红测先行（预载常驻/真实数据性能阈值/防抖延迟），`ctest -R gpr` 6/6 全绿，xcb 真显示人工复测流畅。
- 段错误调查收尾（2026-10-15）：35000 步 offscreen/xcb 双环境压测与 GPR 组件静态分析均零缺陷、不可复现，按用户裁决结案；SIGSEGV backtrace 探针保留作复现绊线（commit `25bdf96`，stderr `=== SEGV BACKTRACE ===` 段）。
- 测试：`gpr_header` / `gpr_bscan` / `gpr_dataset` / `gpr_track` / `gpr_detector` / `gpr_view` 共 6 个 CTest 目标全部通过（真实数据用例在无数据环境自动跳过）；全量 ctest 21/23（`video_render_capture`、`stop_select_flicker_repro` 为既有失败，主仓库复现相同，与本功能无关）；`git diff --check` 无空白错误。
- 三视口截图证据（本地，不入库）：`.omo/evidence/gpr-display/gpr_view_{1280x720,1920x1080,3840x2160}.png`（`gpr_screenshot_tool` 离屏渲染，人工目检通过）。
- 未验证门禁：功能设计 §7 第 4 项（人工运行 §3.1 主流程完整走查：播放 → 目标标记 → 确认 → 态势页目标表/地图/日志联动）未执行，需人工在显示环境中走查后本需求方可转为 `Implemented`。
