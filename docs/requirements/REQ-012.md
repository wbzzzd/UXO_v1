# REQ-012: 数据平台接入

| 字段 | 值 |
|------|-----|
| ID | REQ-012 |
| 所属 | 独立候选（不并入 NEXT 切片） |
| 状态 | `Approved` |

## 能力

指挥席客户端经 UXO 数据平台 API v1 契约（`UXO_DataPlatform/docs/api/v1-contract.md` v1.0.3）接入本地数据平台：构建客户端适配器库（Integration），覆盖健康检查、词表与模型类映射加载、五实体（隐患目标/设备/处置任务/告警/检测记录）查询与上报、分页与过滤、契约错误模型映射，并以本地数据平台实例完成契约一致性验证

## 解决的当前缺口

- `ARCHITECTURE.md` §3 登记的"外部数据边界未开始（无网络、存储、设备或服务适配器）"；根 CMake 查找 `Qt5::Network`/`Qt5::Sql` 但无生产目标链接使用。
- `ARCHITECTURE.md` §4 与 §6.4 登记的"外部态势、历史/审计和持久化责任尚未确定"：本需求确立持久化边界——历史与持久化责任在数据平台（外部环境），客户端经 v1 契约访问，不直连数据库、不在客户端侧另建存储。
- 契约双仓评审（2026-10-10 本仓结论"通过（附非阻断意见）"，记录于 `.omo/plans/20261010-dataplatform-contract-review.md`）是客户端适配器开发的启动门禁，本需求即该评审之后的接入立项。

## 备注

- 本需求是 NEXT 切片之外的独立候选，不并入 NEXT 切片，不改变 NEXT 切片的排除范围；NEXT 排除范围中的"外部通信、持久化"仅在本需求登记的最小边界内解除：客户端 ⇄ 本地数据平台实例（默认 `127.0.0.1:8080`），经 HTTP/JSON v1 契约，不接生产库、不直连数据库。
- 契约关联的"REQ-002"是 UXO_DataPlatform 仓的需求 ID，与本仓 REQ-002（模拟设备指派）同名不同物，引用时必须区分仓库。
- 安全边界：本需求依据 `PRODUCT.md` §5.5"获批后的外部系统客户端接入边界"立项；数据库服务本身为外部环境（§5.5），真实数据库接入的单独评审即本需求与对应功能设计；不因此解除真实设备控制、排弹动作、安全关键动作的禁止边界。
- 适配器只写入契约定义的实体资源；客户端模拟链数据不得作为真实数据上报（详见功能设计非目标）。

对应功能设计见 [`features/data-platform-integration.md`](../features/data-platform-integration.md)。
