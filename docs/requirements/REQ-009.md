## 能力

无人机探测态势演示

## 解决的当前缺口

REQ-008 时间线驱动方案不符合真实无人机工作流，坐标使用本地米坐标系无法对接真实经纬度，地图无无人机位置显示

## 验收结果

态势页中心区为 2D 战术地图（卫星底图 + 经纬度坐标）+ UAV-1 视频区；空起步；点击开始后无人机遥测模拟器沿预设航线持续输出 GPS 坐标，视频同步播放，检测模拟器在画面中发现目标时输出检测结果（类型 + 画面红框 + 置信度），目标地表坐标由无人机 GPS + 画面位置推算；检测触发四区同步（冻结标注证据捕获、目标表插行、地图标点、告警/日志）；地图实时显示无人机位置和航迹；视频为 HUD-only（十字准星、REC、遥测叠加），不在实时画面上绘制检测框；视频结束后目标保留；重置清空所有；结束停止视频并回 0s、保留已有目标；冻结标注证据由详情浮层在目标被选中时显示；点击地图标点/目标表行双向高亮；所有模拟数据标注模拟或演示

## 实现事实

2026-08-21 实现事实：态势演示链路已实现并经 Pull Request 合入主干：态势页 2D 战术地图（卫星底图 + 经纬度坐标）+ UAV-1 HUD-only 视频 + 无人机遥测模拟 + 目标坐标推算 + 检测触发四区同步，空起步/开始/结束/重置状态机齐备。2026-08 起 `DetectionSimulator` 模拟检测链路被 `DetectionEngine`（PatchCore + YOLOv8-cls 两阶段 ONNX 推理）替代并停止接线（代码保留为回退），见 [detection-onnx-integration.md](../features/detection-onnx-integration.md)。当前合并态 Release ctest 15/17：`demo_scenario_provider`、`simulation_workflow`、`simulation_workflow_ui` 等 15 项通过；`video_render_capture` 与 `stop_select_flicker_repro` 2 项失败为探测模型零检出的既有问题（根因 PatchCore `DetectionEngine` 阈值行为，随主干 ONNX 集成引入，登记见 `.omo/plans/20260813-ui-visual-upgrade.md` 执行记录）。遥测与场景为本地模拟数据，检测为本地 ONNX 模型推理，不接真实传感器、真实数据库或外部通信。
