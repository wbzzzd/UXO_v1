## 能力

最小应急起降带（MOS）规划

## 解决的当前缺口

跑道受损后无可用起降区域规划与递进修复方案

## 验收结果

在模拟损毁跑道上输出满足最小起降尺寸的轴对齐起降带，并按修复程度递增给出多方案；仅本地模拟数据，不接真实传感器、真实 AI、真实数据库或通信

## 批准事实

2026-08-03 批准事实（历史记录）：MOS P0 功能与决策页 UI 被用户接受；当前参数仅被接受为合成本地测试 fixture，不代表真实安全、工程或作业参数；架构/性能/安全文档通过 agent 评审，技术评审门禁在修正阻塞性问题后通过；本次批准仅授权进入实现计划阶段，不授权直接代码实现，也不授权真实设备控制、真实 AI、真实数据库、真实通信、真实安全参数或任何真实执行。

## 实现事实

2026-08-04 实现事实：P0 Qt 实现、测试与实际运行验证已完成。fresh Release CTest 15/15 通过；性能门禁（5 测量进程 / 100 预热 / 1000 样本）实测 core p95 1.716ms / p99 1.968ms / max 2.061ms，点击到渲染 p95 12.035ms / max 16.446ms，10ms heartbeat lateness max 1.093ms，100 个全新进程 canonical hash 一致，RSS 门禁通过；三视口视觉证据为 24 PNG / 18 TSV / 0 overflow rows；xcb 官方入口打印启动成功并存活至 10 秒超时。全部基于本地合成模拟数据，不接真实传感器、真实 AI、真实数据库或通信。fresh 运行态证据见 `.omo/evidence/mos-p0-qt-closure-final/`（非版本化产品工件）。
