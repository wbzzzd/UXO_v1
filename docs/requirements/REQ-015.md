# REQ-015: 真实 M4E 无人机数据接入

| 字段 | 值 |

| ID | REQ-015 |
| 所属 | 独立候选（不并入 NEXT 切片） |

## 能力

指挥席客户端 `UXOMissionControl` 接入真实 DJI M4E 无人机数据：经现场内网链路（MSDK App 出口 → EMQX → 客户端；App → 视频服务 → 客户端）接收真实遥测（OSD）、实时视频与 HMS 事件；态势页呈现真实航迹与实时视频，HMS 事件入告警；REQ-009 本地模拟链路保留为可切换、互斥的数据源

## 解决的当前缺口

REQ-009 态势演示的遥测（`DroneTelemetrySimulator`）、视频（本地文件播放）与目标坐标（检测推算）全为本地模拟数据，客户端无任何真实无人机数据入口；客户端与现场内网链路（EMQX/视频服务/PostgreSQL）之间无连接

## 验收结果

（2026-10-10 用户批准）

- **真机链路验收（唯一验收层，依赖 App 侧改造完成与 M1 接口冻结）**：真机 M4E 开机静止状态下，客户端显示真实遥测/实时视频/HMS 事件；手持或短距移动后态势地图显示真实航迹；UI 常显"真实数据"标识（模拟链路仅作开发与 CI 测试工具，不作验收依据，见备注）
- **数据源切换**：REQ-009 模拟演示链路与真实链路可切换、互斥运行，当前数据源在 UI 常显
- **只读边界**：本需求范围内无任何下行指令——客户端代码层不存在控制发布路径；直接飞行控制（杆量/起降/云台等实时操控）为安全边界持续禁止项，航迹规划等任务设置类指令属后续独立功能；Release 构建退出 0，ctest 不低于实施前基线
- **实施与验收记录（2026-10-20 用户裁定关单）**：WP7 RC 台架长跑验收 8 项 7 过 1 环境受限（⑧室内无 GPS 真实航迹：21,203 帧位置三件套 0% 非空，注入器为联调临时手段不产品化）；④ 实时视频出图以三重证据 + 四阶段 127 次断流周期 100% 自愈 + 数据面两级检测实战通过；Release 构建退出 0，ctest 补跑 18/20 与实施前基线一致（#5/#6 预存环境性失败）；完整验收记录与证据见 `.omo/evidence/wp7-rc-integration/wp7-acceptance-report.md`（gitignored 本地留档）；收尾缺陷 A1–A6 见同目录 `wp7-rc-app-defects.md`。

## 备注

- 本需求**改变现有安全边界**，批准即构成用户的明确授权：引入只读外部数据接入（MQTT 订阅、视频拉流）与轨迹库写入（PostgreSQL）。本需求范围不包含任何下行链路（2026-10-09 用户厘清边界表述）：直接飞行控制（杆量/起降/云台等实时操控）属安全边界持续禁止项，任何需求不得引入；航迹规划等任务设置类指令是产品能力（REQ-007 MOS 规划已实现本地功能），下发至真实无人机属后续独立功能，不在本需求。轨迹库写入范围如需收窄，在功能设计待确认事项中裁决。
- App 侧改造（MSDK 安卓 App 出口层替换及必要字段补采）由**本项目接续进行**（2026-10-10 用户确认）：同事已移交 Test 工程（`D:\工作\排弹\测试数据\Test`，独立 git 仓库，含《UAS项目交接文档.md》协议规格/安全缺口/已验证结论），后续 App 改造由本项目承担，代码不收入本仓；真机验收依赖 M1 接口冻结与 App 侧改造完成。
- 范围裁决（2026-10-09 用户确认）：**不含激光测距打点目标**。上游来源资料（SRS/SDD/硬件规格书）无此需求，`measure_target_*` 系开工包反推字段；目标坐标来源保持 REQ-009 检测推算路径。
- 开工包定位与模拟链路（2026-10-09 用户裁决）：开工包降为参考材料，不合理处直接抛弃——SRS 不进真实链路、对接操作指南作废、部署物不收编（本仓自写极简 compose：EMQX；PostgreSQL 待功能设计待确认事项裁决）；接口报文规格作为双方契约收编进本仓 `docs/interfaces/`（2026-10-10 治理裁决自 `deploy/` 迁址）。模拟链路降级为开发/CI 测试工具，不作验收依据（有真机，正式验收即真机：开机静止验遥测/视频/HMS，短距移动验航迹）。
